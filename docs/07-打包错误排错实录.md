# 打包错误排错实录

> 这是本项目从开发到成功打包过程中遇到的所有错误。每个错误都包含：报错信息、根本原因、修复方法、涉及的知识点。
> 以后遇到类似的报错，可以来这里对照排查。

---

### 错误 1：`Failed to fetch invoice`

**报错信息**：
```
Error: Failed to fetch invoice.
  at fetchInvoiceById (app/lib/data.ts:166:11)
```

**根本原因**：Next.js 16 中动态路由的 `params` 是 Promise，必须 `await`。原代码直接 `params.id` 得到 `undefined`，传给 SQL 查询导致报错。

**错误代码**：
```tsx
export default async function Page({ params }: { params: { id: string } }) {
  const id = params.id;  // undefined！因为 params 是 Promise，不是普通对象
```

**修复**：
```tsx
export default async function Page({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;  // 正确：先 await，再解构
```

**涉及知识点**：Next.js 16 路由系统、动态路由 `[id]`、async/await

### 错误 2：`Module not found: Can't resolve '@/app/lib/actions'`

**报错信息**：
```
Module not found: Can't resolve '@/app/lib/actions'
  import { updateInvoice } from '@/app/lib/actions';
```

**根本原因**：文件名是 `action.ts`（单数），但 import 路径写成了 `actions`（多了一个 s）。

**修复**：把所有 `@/app/lib/actions` 改为 `@/app/lib/action`。项目中有 3 处犯了同样的错误：
- `app/ui/invoices/edit-form.tsx`
- `app/ui/invoices/buttons.tsx`
- `app/ui/login-form.tsx`

**教训**：这种拼写错误很常见。遇到 "Module not found" 时，先检查文件名和 import 路径是否完全一致。

**涉及知识点**：模块导入、路径别名 `@/`

### 错误 3：`The name 'DeleteInvoice' is defined multiple times`

**报错信息**：
```
the name `DeleteInvoice` is defined multiple times
```

**根本原因**：同一个文件里 `DeleteInvoice` 函数被定义了两次——一个空的，一个带实际删除逻辑的。

**修复**：删除空的那个定义，只保留带 `deleteInvoice.bind(null, id)` 实际逻辑的版本。

**教训**：复制粘贴代码后记得删掉旧版本。

### 错误 4：`The Middleware file must export a function named 'middleware' or a default function`

**报错信息**：
```
The Middleware file "/middleware" must export a `middleware` or a default function.
```

**根本原因**：`export default NextAuth(authConfig).auth` 这种链式写法，Next.js 16 无法识别它是一个有效的函数导出。

**错误代码**：
```tsx
export default NextAuth(authConfig).auth;
```

**修复**：拆成两步，用命名导出：
```tsx
const { auth } = NextAuth(authConfig);
export const middleware = auth;
```

**涉及知识点**：Next.js middleware、ES 模块导出（命名导出 vs 默认导出）

### 错误 5：`Cannot find name 'signOut'`

**报错信息**：
```
Type error: Cannot find name 'signOut'.
  await signOut();
```

**根本原因**：`sidenav.tsx` 里在内联 Server Action 中调用了 `signOut()`，但没有导入。

**修复**：在文件顶部添加 `import { signOut } from '@/auth';`

**教训**：TypeScript 的 "Cannot find name" 错误几乎都是忘了 import。检查该函数/变量在哪里定义的，然后在文件头部导入。

### 错误 6：`form action` 类型不匹配（deleteInvoice / updateInvoice）

**报错信息**：
```
Type '() => Promise<{ message: string; }>' is not assignable to type
'(formData: FormData) => void | Promise<void>'
```

**根本原因**：`<form action={fn}>` 要求绑定的函数返回 `void`（无返回值），但 `deleteInvoice` 和 `updateInvoice` 的 catch 分支返回了 `{ message: string }` 对象，类型不兼容。

此外，`deleteInvoice` 中有一行测试代码 `throw new Error('Failed to Delete Invoice')` 写在 `try` 前面，导致后面的正常逻辑永远不会执行。

**错误代码**：
```tsx
export async function deleteInvoice(id: string) {
    throw new Error('Failed to Delete Invoice');  // ← 这行在 try 前面，永远抛错
  try {
    await sql`DELETE FROM invoices WHERE id = ${id}`;
    revalidatePath('/dashboard/invoices');
    return { message: 'Deleted Invoice.' };  // ← 返回对象，但 form action 要求 void
  } catch (error) {
    return { message: 'Database Error: Failed to Delete Invoice.' };  // ← 同样的问题
  }
}
```

**修复**：
```tsx
export async function deleteInvoice(id: string) {
  try {
    await sql`DELETE FROM invoices WHERE id = ${id}`;
    revalidatePath('/dashboard/invoices');
  } catch (error) {
    console.error('Database Error:', error);
    throw new Error('Database Error: Failed to Delete Invoice.');  // throw 而不是 return
  }
}
```

**关键区别**：
- `return { message }` → 返回一个对象给调用者（form action 不接受）
- `throw new Error()` → 抛出异常，会被 `error.tsx` 捕获显示错误页面（正确做法）

**涉及知识点**：Server Actions、form action 的类型约束、throw vs return

### 错误 7：`useFormState` 被改名了

**报错信息**：
```
ReactDOM.useFormState has been renamed to React.useActionState.
Please update LoginForm to use React.useActionState.
```

**根本原因**：React 19 把 `useFormState` 从 `react-dom` 迁移到了 `react`，并改名为 `useActionState`。

**错误代码**：
```tsx
import { useFormState } from 'react-dom';
const [state, dispatch] = useFormState(action, initialState);
```

**修复**：
```tsx
import { useActionState } from 'react';
const [state, dispatch] = useActionState(action, initialState);
```

**注意**：`useFormStatus` 没有改名，还是从 `react-dom` 导入。

**涉及知识点**：React 19 hooks 变化、useActionState vs useFormState

### 错误 8：缺少 NextAuth API 路由

**报错信息**：
```
api/auth/callback/credentials 404
```

**根本原因**：NextAuth 需要一个 API 路由处理器来接收登录请求（如 `POST /api/auth/callback/credentials`）。项目里没有创建这个文件。

**修复**：

第一步：在 `auth.ts` 中导出 `handlers`：
```tsx
export const { auth, signIn, signOut, handlers } = NextAuth({ ... });
```

第二步：创建路由文件 `app/api/auth/[...nextauth]/route.ts`：
```tsx
import { handlers } from '@/auth';
export const { GET, POST } = handlers;
```

**为什么要分 `auth` 和 `handlers`？**
- `auth` — 获取当前用户 session 的函数（用在组件和 middleware 中）
- `handlers` — 处理 HTTP 请求的对象，包含 `GET` 和 `POST` 方法（用在 API 路由中）

**涉及知识点**：NextAuth v5、API 路由 `[...nextauth]` catch-all 路由

### 错误 9：`Property 'GET' does not exist on type`

**报错信息**：
```
Property 'GET' does not exist on type '...'
  export const { GET, POST } = auth;
```

**根本原因**：和错误 8 相关。把 `auth`（session 函数）当成了 `handlers`（路由处理器）来解构。`auth` 没有 `GET`/`POST` 属性。

**修复**：用 `handlers` 而不是 `auth`：
```tsx
import { handlers } from '@/auth';     // ✅ handlers 有 GET 和 POST
export const { GET, POST } = handlers;
```

### 错误 10：Node.js 版本不满足要求

**报错信息**：
```
You are using Node.js 18.20.8. For Next.js, Node.js version ">=20.9.0" is required.
```

**根本原因**：Next.js 16 要求 Node.js >= 20.9.0，但系统默认的 Node.js 版本是 18。

**修复**：
```bash
fnm use 20    # 或 nvm use 20
node -v       # 确认版本 >= 20.9.0
```

**教训**：遇到 "You are using Node.js x.x.x" 报错时，先检查版本是否满足要求。

### 错误总结速查表

| `must export middleware` | 链式导出不识别 | 用命名导出 `export const middleware =` |
| `Cannot find name` | 忘了 import | 添加 import 语句 |
| `not assignable to Promise<void>` | Server Action 返回了对象 | catch 里用 `throw` 而不是 `return` |
| `useFormState renamed` | React 19 改名了 | 改用 `useActionState` from `react` |
| `404 api/auth/callback` | 缺 NextAuth 路由文件 | 创建 `[...nextauth]/route.ts` |
| `Property GET does not exist` | 用错了导出（auth vs handlers） | 用 `handlers` 导出 GET/POST |
| `Node.js version required` | Node 版本太低 | 升级到 Node.js >= 20.9.0 |
